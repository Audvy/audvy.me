AWS Hosted Chatroom

The original real-time chatroom, backed by EC2, SQL, and CloudWatch alerts.

Building the first version

Our team built a Java and Kotlin chat client at the 2024 University at Buffalo Hackathon. Clients connected to a chat server on Amazon EC2, which stored data in a SQL database on a separate instance.

A CloudWatch alarm notified the team through SNS when CPU utilization ran high, giving an administrator the information needed to upgrade the instance as demand grew.
